# COBOL corpus manifest

Built 2026-10-03 for the COBOL-to-Java migration-compiler feasibility study. Every folder is a
`git clone --depth 1` of a public GitHub repository, named after the repo. `scan.sh` regenerates
`scan.tsv` (one row per repo; grep-based feature counts). GnuCOBOL 3.1.2 (`cobc`) is installed on
this machine and was used to verify two oracles below.

Totals (scan.tsv, COBOL files = `*.cbl *.cob *.cobol *.tcbl *.pgm *.pco *.sqb *.eco`):
**24 repos, 5,127 COBOL files, 3,026,979 lines, 901 copybooks, 213 JCL members, 1.1 GB on disk.**
Heavy duplication: the NIST CCVS85 suite (~350k lines) is present in five repos
(nistcobol85, eval-nist-cobol85 [twice: reference + reference-mutated], opensourcecobol4j,
proleap-cobol-parser, TypeCobol). Deduplicated unique COBOL is roughly 1.2M lines, of which
~420k is the CNAF generated programs in TypeCobol and ~250k is gnucobol-contrib.

Feature-count columns are grep hits (lines), case-insensitive, across each repo's COBOL files:
CICS = `EXEC CICS`, SQL = `EXEC SQL`, SORT = `SORT x ON/ASC/DESC/USING/INPUT`, RED = REDEFINES,
ODO = `OCCURS ... DEPENDING`, C3 = COMP-3/COMPUTATIONAL-3, GOTO = `GO TO`, ALTER = statement
`ALTER`, THRU = PERFORM ... THRU/THROUGH.

## Tier 1: realistic applications

### aws-mainframe-modernization-carddemo
- URL: https://github.com/aws-samples/aws-mainframe-modernization-carddemo
- License: Apache-2.0 (LICENSE + NOTICE). Redistributable.
- Dialect: IBM Enterprise COBOL for z/OS (CICS, BMS, VSAM KSDS/AIX, DB2, IMS, MQ options).
- Counts: 44 COBOL programs (30,175 lines), 62 copybooks (`app/cpy`, `app/cpy-bms`), 61 JCL
  (`app/jcl`, `app/proc`, `samples/jcl`), 21 BMS maps, 8 DDL, 12 EBCDIC datasets + 9 ASCII data files.
- Features: CICS 240, SQL 32, SORT 0 (sort is done by a JCL SORT step, job COMBTRAN), RED 106,
  ODO 21, COMP-3 32, GOTO 186, ALTER 0 (the 4 grep hits are `ALTERNATE RECORD KEY`), THRU 70.
- Largest: `app/cbl/COACTUPC.cbl` 4,236 lines (CICS). Batch programs 157 to 924 lines.
- Test data: `app/data/ASCII/*.txt` (acctdata 50, carddata 50, cardxref 50, custdata 50,
  dailytran 300, discgrp 51, tcatbal 50, trancatg 18, trantype 7 records) and the same in EBCDIC
  (`app/data/EBCDIC/AWS.M2.CARDDEMO.*.PS`, fixed-length, no line terminators).
- Expected outputs: **none checked in**. Oracle must be generated by running under GnuCOBOL.
- Batch (no CICS, no SQL) programs, all pure file I/O, candidates for oracle generation:
  - `app/cbl/CBACT01C.cbl` account file reader/print (430 lines; compiles clean with
    `cobc -x -std=ibm -I app/cpy`)
  - `app/cbl/CBACT02C.cbl` card file reader (178)
  - `app/cbl/CBACT03C.cbl` xref reader (178)
  - `app/cbl/CBACT04C.cbl` interest calculation, JCL INTCALC (652; GnuCOBOL needs `-m` or a driver
    because PROCEDURE DIVISION has USING)
  - `app/cbl/CBCUS01C.cbl` customer reader (178)
  - `app/cbl/CBTRN01C.cbl` daily transaction validation (494)
  - `app/cbl/CBTRN02C.cbl` transaction posting, JCL POSTTRAN (731; compiles clean)
  - `app/cbl/CBTRN03C.cbl` transaction report, JCL TRANREPT (649; compiles clean)
  - `app/cbl/CBSTM03A.CBL` + `CBSTM03B.CBL` statement generation (text + HTML), JCL CREASTMT (924 + 230)
  - `app/cbl/CBEXPORT.cbl`, `CBIMPORT.cbl` (582, 487)
- Caveat: inputs are VSAM KSDS; the ASCII data files are sequential and must be loaded into
  GnuCOBOL indexed files (a small loader program or `-std=ibm` with sequential override) first.
  The JCL (`app/jcl/POSTTRAN.jcl` etc.) documents the DD-to-file mapping.

## Tier 2: conformance suites (the oracle backbone)

### nist-cobol85-test-suite
- URL: https://github.com/Zaneham/nist-cobol85-test-suite
- License: public domain (US government work, NIST CCVS85 v4.0, Oct 1992), README states it.
- Single file `newcob.val` (348,271 lines, 512 `*HEADER` entries: 459 COBOL programs, 51 COPY
  members, 2 DATA files). Needs EXEC85 (the first program in the file) to split.
- Fetched by `fetch.sh` at commit `0428c3cf` and checked by SHA-256 (`744a0498...3274`): the source of
  the NIST run in `oracle/` (R-044).

### nistcobol85 (z390development)
- URL: https://github.com/z390development/nistcobol85
- License: no LICENSE file; content is the public-domain NIST suite plus z390 scripts.
- `src/`: 486 extracted `.CBL` (357,511 lines), 51 `.CPY`, 2 `.DAT`, plus `split_val.py`, and
  `doc/` with CCVS85 User Guide 4.2, NISTIR 5731, NIST SP 500-203 (intrinsic functions) PDFs.
- Modules: NC 95 (nucleus), SM 17 (source manipulation/COPY), IC 47 (inter-program), SQ 85
  (sequential I/O), RL 35 (relative), IX 42 (indexed), ST 40 (SORT/MERGE), SG 13 (segmentation),
  OB 9 (obsolete), IF 45 (intrinsic functions), RW 6 (report writer), DB 15 (debug), CM 9
  (communication, not compilable by GnuCOBOL).
- Features (dialect COBOL-85 standard): SORT 29, RED 4,597, ODO 17, GOTO 21,983, **ALTER 193**,
  THRU 2,546, no COMP-3 (standard has no COMP-3; uses COMP).

### eval-nist-cobol85 (AnyEval)
- URL: https://github.com/AnyEvalOrg/eval-nist-cobol85
- License: Apache-2.0 for package code; NIST material public domain (NOTICE.md).
- **This is the oracle-ready set.** `reference/<MODULE>/` holds, for each NIST program, the expanded
  `.CBL`, GnuCOBOL 3.2.0 compile output (`.cobc.out`), stdout (`.out`) and the printed self-checking
  REPORT (`.log`, 400 files >1 KB, 388 containing PASS lines). `reference-mutated/` repeats this with
  planted faults. Generated 2026-09-20 via EXEC85/expand.pl/report.pl (`reference/run_nist.sh`).
- Verified locally: `cobc -x -std=cobol85 reference/NC/NC101A.CBL` then run produces a `REPORT`
  file identical (0 diff lines after trailing-space strip) to `reference/NC/NC101A.log`.
- Per-module reference logs: NC 92, SM 16, IC 25, SQ 83, RL 33, ST 34, SG 11, OB 8, IF 43, RW 5,
  DB 10, IX 40 = **400 program runs with expected REPORT output**.
- Caveat: DATE/TIME-stamped lines are absent in NC101A but some modules print ACCEPT FROM DATE;
  SQ/RL/IX modules write and read their own files; a few (interactive ACCEPT, DB debug) are
  excluded by the package's own eligibility script (`scripts/mutate_suite.py`).

### gnucobol (OCamlPro mirror of GnuCOBOL trunk)
- URL: https://github.com/OCamlPro/gnucobol
- License: GPL-3.0+ (compiler), LGPL-3.0+ (libcob); the test suite is GPL.
- `tests/testsuite.src/*.at`: 1,447 autotest cases; `run_*.at`/`data_*.at` hold 900 cases with
  812 inline `prog.cob` programs and 839 `./prog` run checks, of which **359 assert a non-empty
  expected stdout** (byte-exact). Each is a 10-80 line program: fundamental semantics (MOVE edit
  pictures, COMP-3/BINARY truncation, ROUNDED, intrinsic functions, REDEFINES, file I/O, SORT,
  REPORT WRITER, ODO). `tests/cobol85/` holds the NIST driver (`NC.txt` etc. are expected pass
  counts, `summary.txt` the expected totals: 426 programs, 9,610 passes, 0 fails).
- Only 4 standalone `.cob` files; the programs live inside the `.at` files and must be extracted.

### opensourcecobol4j (opensource COBOL 4J, COBOL-to-Java compiler)
- URL: https://github.com/opensourcecobol/opensourcecobol4j
- License: GPL-3.0 / LGPL-3.0.
- 422 COBOL (320,239 lines): `tests/cobol85/*/` holds 414 NIST `.CBL` plus 2 `.DAT` and 1 `.SUB`,
  with `summary.txt` of expected pass counts; `tests/*.src` hold more inline autotests
  (`data-rep`, `cobj-idx`, `cobol_utf8`, `command-line-options`). Directly relevant prior art:
  a Java backend that already passes the NIST suite.

### opensource-cobol (older, GnuCOBOL 1.1 fork)
- URL: https://github.com/opensourcecobol/opensource-cobol ; GPL-2.0+/LGPL. 2 COBOL files plus
  autotests in `tests/*.src`. Low value beyond opensourcecobol4j.

### proleap-cobol-parser
- URL: https://github.com/uwol/proleap-cobol-parser ; MIT.
- 759 COBOL (349,204 lines): `src/test/resources/gov/nist/` the NIST suite again, plus
  `src/test/resources/io/proleap/cobol/` ~300 small feature programs each with a `.tree`
  parse-tree expectation (55 files). Parser oracle, not runtime oracle.

## Oracle-ready programs (batch, with input and expected output checked in)

1. **NIST CCVS85 via eval-nist-cobol85/reference** : 400 programs with reference REPORT (`.log`) and
   stdout (`.out`), self-contained (inputs are generated by the programs or shipped as `.DAT`/`.SUB`).
   Verified reproducible with GnuCOBOL 3.1.2 for NC101A. Paths:
   `eval-nist-cobol85/reference/{NC,SM,IC,SQ,RL,ST,SG,OB,IF,RW,DB,IX}/<PROG>.CBL` with
   `<PROG>.log` as expected output. Public domain.
2. **GnuCOBOL autotests** : 359 inline programs in `gnucobol/tests/testsuite.src/run_*.at` and
   `data_*.at` with byte-exact expected stdout in the following `AT_CHECK` (extraction script needed).
   GPL (tests), but each program is a few lines; the expected-output assertions are the asset.
3. **Cobol-mainframe/Employeebatch.cbl** with `sample input txt` and `expected-output.txt` (trivial).
4. **dscobol Cobol-Code ABCFP chapter 10** master/transaction update programs
   (`GnuCOBOL/Tutorials/ABCFP/cbl/BDS1001-BDS1005.cbl`) with inputs `data/c10-*master|trans.dat.txt`
   and outputs `data/c10-*newmast.dat.txt` checked in (unlicensed; verify by running).

Total oracle-ready: **~760 programs** (400 NIST + 359 GnuCOBOL + 1 + ~5), all small-to-medium
(NIST programs 100-3,100 lines; GnuCOBOL tests 10-80 lines).

## Oracle-generatable (batch, inputs present, expected output must be produced by GnuCOBOL)

- CardDemo: 12 batch programs listed above with `app/data/ASCII/*.txt` (Apache-2.0). The single
  best "realistic business batch" set; 2 of 3 tried compile clean with `cobc -std=ibm`.
- BankDemo: `sources/cobol/core/ZBNK*.cbl` batch with `datafiles/*.dat` (restrictive license).
- gnucobol-contrib tools: cobxref, cntlines, printcbl, changeformat, GCSORT (GPL).
- dscobol ECBAP: 47 programs with ~20 input files (unlicensed).

- ACAS (SourceForge git, ~500k lines GPL accounting system): network allowlist refused

  replaced by "cobol"), every link dead or irrelevant.
- `xkyleann/COBOL` cloned and removed: Markdown notes only, no COBOL files.
- `BloopAI/COBOLEval` cloned and removed: programs live inside a JSONL (HumanEval ports), MIT;
  146 small algorithmic tasks with test harness, synthetic rather than realistic.
